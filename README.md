# Ansible Demo Project

Учебный проект: автоматизация управления Linux-хостом через Ansible — установка nginx, управление конфигурацией, идемпотентные плейбуки.

## Структура проекта

- `nginx.yml` — плейбук установки и настройки nginx
- `my_index.html` — кастомная страница сайта
- `hosts.ini` — инвентарь (управляемые хосты)
- `ansible.cfg` — настройки Ansible (путь к инвентарю)
- `hello.yml` — учебный плейбук: первый запуск Ansible
- `info.yml` — учебный плейбук: сбор информации о хосте
- `playbooks/` — отдельные плейбуки:
  - `check-facts.yml` — сбор базовой информации о системе
  - `check-uptime.yml` — проверка uptime с условными предупреждениями
  - `debug-groups.yml` — отладка групп хостов

## Возможности

- Установка nginx и управление службой через Ansible
- Кастомная страница вместо дефолтной (управление файлами через `copy`)
- Идемпотентные плейбуки: повторный запуск не вносит лишних изменений
- Условная логика (`when`): предупреждение при недавней перезагрузке
- Инвентарь прописан в `ansible.cfg`, флаг `-i` не нужен

## Как запустить

1. Проверка синтаксиса:
   ```bash
   ansible-playbook --syntax-check nginx.yml
```

2. Проверка связи с хостом:
   ```bash
   ansible linux -m ping
```

3. Запуск отедельной проверки:
   ```bash
   ansible-playbook playbooks/check-uptime.yml
```

4. Применение плейбука:
   ```bash
   ansible-playbook nginx.yml
```
