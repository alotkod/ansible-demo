# Ansible Demo Project

Учебный проект: автоматизация управления разнородной инфраструктурой (Linux + Windows) через Ansible. Демонстрация установки веб-серверов (nginx и IIS), работы с секретами и идемпотентных плейбуков.

## Структура проекта

- `nginx.yml` — плейбук установки и настройки nginx на Linux
- `win_iis.yml` — плейбук установки и настройки IIS на Windows
- `my_index.html` — кастомная страница сайта (используется для обоих серверов)
- `hosts.ini` — инвентарь (управляемые хосты Linux и Windows)
- `ansible.cfg` — настройки Ansible (путь к инвентарю)
- `hello.yml` — учебный плейбук: первый запуск Ansible
- `info.yml` — учебный плейбук: сбор информации о хосте
- `playbooks/` — отдельные плейбуки:
  - `check-facts.yml` — сбор базовой информации о системе
  - `check-uptime.yml` — проверка uptime с условными предупреждениями
  - `debug-groups.yml` — отладка групп хостов
- `group_vars/` — переменные для групп хостов:
  - `windows.yml.example` — шаблон переменных для подключения к Windows (WinRM)

## Возможности

- **Linux-автоматизация**: установка nginx, управление службой, кастомная страница, идемпотентные плейбуки.
- **Windows-автоматизация**: установка роли IIS (`win_feature`), управление службой W3SVC, развертывание контента через `win_copy`.
- **Безопасность секретов**: реальные пароли не попадают в Git. Для подключения к Windows используется шаблон `windows.yml.example`, который нужно скопировать в `windows.yml` и заполнить своими данными.
- **Идемпотентность**: повторный запуск плейбуков не вносит лишних изменений (статус `changed=0` при повторном прогоне).
- **Условная логика**: примеры использования `when` для предупреждений при недавней перезагрузке.
- **Кроссплатформенность**: единый инвентарь и подход к управлению разными ОС.

## Как запустить

1. Проверка синтаксиса:
   ```bash
   ansible-playbook --syntax-check nginx.yml
   ```

2. Проверка связи с хостом:
   ```bash
   ansible linux -m ping
   ```

3. Запуск отдельной проверки:
   ```bash
   ansible-playbook playbooks/check-uptime.yml
   ```

4. Применение плейбука:
   ```bash
   ansible-playbook nginx.yml
   ```
